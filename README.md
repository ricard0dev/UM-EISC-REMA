📚 Trabalho de Grupo — Git e GitHub
📌 Descrição do Projeto

Este projeto tem como objetivo demonstrar a utilização do Git e do GitHub para o controlo de versões e a colaboração entre os membros de uma equipa.

Durante o desenvolvimento do trabalho, serão utilizadas funcionalidades como a criação de repositórios, branches, commits, merges e pull requests.

🎯 Objetivos
Compreender o funcionamento do Git.
Aprender a utilizar o GitHub.
Trabalhar em equipa através de um repositório partilhado.
Praticar o controlo de versões.
Aprender a resolver conflitos de código.
Organizar e documentar um projeto colaborativo.

https://git-scm.com/

2. Clonar o repositório

3. Entrar na pasta do projeto
bash
cd trabalho-grupo-git

🔄 Comandos Git Utilizados
Verificar o estado dos ficheiros
bash
git status

Adicionar ficheiros
bash
git add .

Guardar alterações
bash
git commit -m "Descrição das alterações"

Enviar alterações para o GitHub
bash
git push

Atualizar o projeto local
bash
git pull

Criar uma nova branch
bash
git branch nome-da-branch

Mudar de branch
bash
git switch nome-da-branch

Integrar alterações de outra branch
bash
git merge nome-da-branch

🌿 Metodologia de Trabalho

Para facilitar a colaboração, o grupo seguirá os seguintes passos:

O grupo cria um repositório no GitHub.
Cada membro clona o repositório para o seu computador.
Cada membro cria uma branch para desenvolver a sua tarefa.
As alterações são guardadas através de commits.
Cada membro envia as alterações para o GitHub.
São criados pull requests para rever as alterações.
Após a revisão, as alterações são integradas na branch principal.
O grupo atualiza a documentação do projeto.

📏 Regras de Colaboração
Cada membro deve trabalhar na sua própria branch.
Os commits devem ter mensagens claras e descritivas.
Antes de começar a trabalhar, deve executar-se git pull.
As alterações devem ser testadas antes de serem enviadas.
Os conflitos devem ser resolvidos em conjunto, quando necessário.
O código deve ser revisto antes de ser integrado na branch principal.
